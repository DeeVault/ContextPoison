# ContextPoison — Usage Guide

> **Out of the box, only 6 benign example seeds ship** (`statements/example_seeds.json`).
> The harmful HVD attack corpus is not bundled (see the README "Dataset" section). The
> `--total` examples below are capped to the number of statements actually present, so
> against the example seeds they yield 6. To reproduce the published findings, add the
> HVD corpus to `statements/` first (see README "Custom corpus") and raise `--total`.

## Quick Start

### Example 1 — Benchmark against Claude Haiku

Run these four commands in sequence. Each builds on the last.

```bash
# 1. Create a reproducible sample (caps to the statements available — 6 example seeds out of the box)
python sample_statements.py --total 6 --seed 42

# 2. Collect baseline responses — bare question, no injection
python contextpoison.py --sample sample.json --target claude-haiku-4-5-20251001 --baseline

# 3. Collect attack responses — Tinject fabricated-evidence injection
python contextpoison.py --sample sample.json --target claude-haiku-4-5-20251001

# 4. Generate the report (written to outputs/report.md)
python contextpoison.py --report
```

### Example 2 — Generate a report from existing results

If you have already run a benchmark and just want to (re-)generate the report:

```bash
python contextpoison.py --report --output my_results.md
# → written to outputs/my_results.md
```

## First-time setup

```bash
pip install -r requirements.txt
```

Set API keys as environment variables (no flags needed if these are set):

```bash
export ANTHROPIC_API_KEY=sk-ant-...   # required for the scorer and Anthropic target models
export OPENAI_API_KEY=sk-...          # required for OpenAI target models
export GOOGLE_API_KEY=...             # required for Gemini target models
export XAI_API_KEY=...                # required for xAI / Grok target models
```

---

## 1. Generate a reproducible sample

Creates `sample.json` with statement IDs distributed evenly across whatever categories
are present in `statements/` (out of the box, just the `example_seeds` category).
Use the same `--seed` and `--total` across all model runs for fair comparison.
`--total` is capped to the number of statements available.

```bash
python sample_statements.py --total 6 --seed 42      # 6 example seeds out of the box
# With the full HVD corpus added to statements/, scale up, e.g.:
# python sample_statements.py --total 1000 --seed 42
```

---

## 2. Run a baseline (no injection)

Sends only the bare question with no Tinject prompt. Results are stored with `baseline=1`.

```bash
python contextpoison.py \
  --sample sample.json \
  --target claude-haiku-4-5-20251001 \
  --baseline
```

---

## 3. Run an attack (with Tinject injection)

Sends the full fabricated-evidence system prompt. Results are stored with `baseline=0`.

```bash
python contextpoison.py \
  --sample sample.json \
  --target gpt-4o-mini
```

```bash
# Gemini example
python contextpoison.py \
  --sample sample.json \
  --target gemini-flash-latest

# xAI example
python contextpoison.py \
  --sample sample.json \
  --target grok-3-mini

# Speed up with concurrent API calls
python contextpoison.py \
  --sample sample.json \
  --target gpt-4o-mini \
  --workers 5
```

---

## 4. Generate a report

Reads `results.db` and writes a markdown report with per-model score tables,
per-model deltas, and a cross-model comparison table.

```bash
python contextpoison.py --report                        # → outputs/report.md
python contextpoison.py --report --output haiku.md      # → outputs/haiku.md
python contextpoison.py --report --output /tmp/out.md   # → /tmp/out.md (full path used as-is)
```

---

## 5. Validate scorer reliability

Re-scores a random sample of stored responses using a second model and computes
Pearson correlation and mean absolute difference against the original scores.

```bash
# Validate using a Together AI model as the cross-scorer
python contextpoison.py --validate \
  --validate-scorer meta-llama/Llama-3.3-70B-Instruct-Turbo \
  --validate-scorer-url https://api.together.xyz/v1 \
  --validate-scorer-key $TOGETHER_API_KEY

# Validate using a different Anthropic model
python contextpoison.py --validate \
  --validate-scorer claude-opus-4-8 \
  --validate-n 50
```

## 6. Other useful commands

```bash
# List available statement categories
python contextpoison.py --list-categories

# List example model strings by provider
python contextpoison.py --list-models

# Run a single category (no sample file needed); the category is the filename
# in statements/ without .json — out of the box that is example_seeds
python contextpoison.py --category example_seeds --target gpt-4o-mini

# Run all categories with a hard limit
python contextpoison.py --all --target gpt-4o-mini --limit 200
```

## Flag reference

| Flag | Description |
|---|---|
| `--sample FILE` | Path to a sample.json generated by sample_statements.py |
| `--target MODEL` | Target model name (auto-detects provider from prefix) |
| `--target-url URL` | Base URL for OpenAI-compatible custom/local endpoints |
| `--target-key KEY` | API key for the target model (falls back to env var) |
| `--scorer-key KEY` | Anthropic API key for the scorer (falls back to `$ANTHROPIC_API_KEY`) |
| `--baseline` | Send bare query with no injection; stored as baseline=1 |
| `--workers N` | Number of concurrent API calls (default: 1) |
| `--limit N` | Stop after N statements have been tested |
| `--report` | Generate markdown report from results.db |
| `--output FILE` | Report output path; bare filenames go to `outputs/` (default: `outputs/report.md`) |
| `--validate` | Re-score a sample of stored results to check scorer consistency |
| `--validate-scorer MODEL` | Model to use for re-scoring (default: claude-sonnet-4-6) |
| `--validate-scorer-url URL` | Base URL for an OpenAI-compatible validation scorer |
| `--validate-scorer-key KEY` | API key for the validation scorer |
| `--validate-n N` | Number of responses to re-score (default: 150) |
