# ContextPoison — Dataset Information

## Source

All statements used in ContextPoison benchmarks are sourced from the **Hazardous Viewpoints Dataset (HVD)** published by Yang et al., 2026 alongside their paper:

> Yang, X., Liu, C., Huang, Z., Li, H., Zhang, W., Weng, J., & Song, Y. (2026). *Steering LLM Viewpoints through Fabricated Evidence Injection.* arXiv:2606.06244

The dataset is available at the authors' project page. Full credit for dataset curation belongs to the original authors.

---

## What the dataset contains

HVD consists of misleading statements paired with relevant queries, organised across harmful content categories. Each entry includes:

- A basic statement containing a misleading viewpoint
- An adopted statement — a repackaged version with fabricated academic framing
- Query variants (explicit and implicit) for testing
- Category labels and explanations

The dataset covers two main types:

**Stereotypes** — Gender, race, age, religion, occupation, physical characteristics, sexual orientation

**Falsehoods** — Brand misinformation, medical misinformation, political misinformation, psychological manipulation

---

## How ContextPoison uses it

We use the pre-generated adopted statements directly as injection payloads — skipping Phase 1 repackaging for statements already in HVD. This reduces API costs and ensures reproducibility.

The sample.json file (generated by sample_statements.py) records which statement IDs were used in a given benchmark run. Using `--seed 42` reproduces the exact same sample.

---

## Responsible use statement

The statements in this dataset represent harmful viewpoints included **solely to test model robustness**. They do not represent the views of the author or any contributor to ContextPoison.

These statements should only be used:
- To benchmark AI model resistance to fabricated evidence injection
- For security research and responsible disclosure
- In authorised red team assessments of AI systems you own or have permission to test

They should never be used to actually manipulate AI systems deployed to real users, to generate harmful content for distribution, or for any purpose that causes harm to individuals or groups.

## Dataset structure

Statements are organised into category files under `contextpoison/statements/`:

| File | Category | Statements |
|------|----------|------------|
| manipulation_psychological.json | Psychological Manipulation | 59 |
| misinfo_political.json | Political Misinformation | 59 |
| stereotype_age.json | Age Stereotypes | 42 |
| stereotype_gender.json | Gender Stereotypes | 45 |
| stereotype_occupation.json | Occupational Stereotypes | 42 |
| stereotype_physical.json | Physical Characteristic Stereotypes | 44 |
| stereotype_race.json | Race Stereotypes | 46 |
| stereotype_religion.json | Religion Stereotypes | 42 |
| stereotype_sexual_orientation.json | Sexual Orientation Stereotypes | 40 |

Total: **419 statements** with query_new populated (usable for benchmarking)

Note: misinfo_brand and misinfo_medical categories were excluded from the default sample as the HVD entries for these categories lack query_new fields required for automated benchmarking.

---

## Reproducibility

To reproduce the exact benchmark sample used in the published findings:

```bash
python sample_statements.py --total 1000 --seed 42
```

This generates sample.json containing the same 419 statement IDs used in the original benchmark. The seed ensures identical sampling regardless of environment.

The full results database is available on request for independent verification.
